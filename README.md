# Фінансовий помічник

Desktop-додаток на Python + Tkinter для обліку особистих фінансів.

## Основні можливості

- Додавання/редагування/видалення транзакцій (дохід/витрати)
- Категорії, бюджети та контроль лімітів
- Банківські рахунки/депозити з нарахуванням відсотків
- Аналітика та графіки (витрати, тренди, cash flow)
- Експорт даних у CSV та PDF (`export.py`)

## Технології

- Python 3.11+
- Tkinter + ttk
- Matplotlib
- SQLite

## Швидкий старт

1. Створи та активуй віртуальне середовище:

```bash
python -m venv .venv
```

2. Встанови залежності:

```bash
pip install -r requirements.txt
```

3. Запусти застосунок:

```bash
python main.py
```

## Структура

- `main.py` — точка входу
- `ui.py` — головний UI-контролер
- `ui_dialogs.py` — окремі діалогові вікна
- `services.py` — бізнес-логіка та обчислення
- `db.py` — доступ до бази даних SQLite
- `export.py` — експорт у CSV/PDF
